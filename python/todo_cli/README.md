# To-Do CLI

**Language:** Python 
**Goal:** Simple command-line to-do list that saves tasks in a JSON file.  

## Features Demonstrated
- Command-line arguments ('sys.argv')
- File I/O and JSON storage
- Loops and conditionals
- Basic error handling

## How to Run
cd python/todo_cli
python3 app.py add "read docs"
python3 app.py list
python3 app.py done 1
