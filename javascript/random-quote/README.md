# Random Quote Generator

**Language:** JavaScript  
**Goal:** <one-sentence problem>  

## Features Demonstrated
- Arrays (storing a list of quotes)
- DOM manipulation (`document.getElementById`)
- Event handling (`onclick`)
- Basic separation of HTML (structure) and JS (behavior)

## How to Run
From this folder:

1. Open `index.html` in a web browser.  
2. Click the **New Quote** button.  
3. A random quote will appear each time you click.

*(Optional: run `python3 -m http.server 8000` in this folder and open `http://localhost:8000` if you want to serve it locally instead of double-clicking.)*
